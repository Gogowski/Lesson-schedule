# Расписание занятий

## Запуск для разработки

Нужен Node.js 22.12+ и npm. Для GitHub Actions и Render версия закреплена в `.node-version` (24.21.0).

```powershell
npm ci
npm run dev
```

Откройте <http://localhost:3000>. Остановить сервер можно сочетанием `Ctrl+C`.

## Сборка и запуск production-версии

```powershell
npm run build
$env:NODE_ENV = 'production'
npm run start
```

Сервер слушает порт `3000`.

## Подготовка к реальному использованию

Production-сайт опубликован по адресу <https://lesson-schedule-k5tj.onrender.com/>. Для входа нужны созданные владельцем аккаунты Supabase; публичная регистрация отключена. План бесплатного размещения, текущий статус и оставшиеся шаги описаны в [REAL_USE_PLAN.md](./REAL_USE_PLAN.md).

ФИО и контакты в расписание добавлять не нужно. Бесплатный вариант — Render Static Site для сайта и Supabase Free для входа и данных. Исходный код хранится в приватном репозитории; расписание хранится в закрытой таблице Supabase и не попадает в файлы сайта. Firebase Spark остаётся необязательным вариантом, но доступность бесплатной настройки не подтверждена.

Локальный API и PIN относятся только к демо-режиму и не входят в Render Static Site. Production-сайт использует Supabase Auth и RLS; до создания аккаунтов и загрузки настоящего расписания он показывает только форму входа.

Подключение Render и базовая конфигурация Supabase завершены. В облаке пока нет пользовательских аккаунтов и настоящего расписания. Инструкция по созданию пользователей, назначению ролей и проверке доступа находится в [supabase/SETUP.md](./supabase/SETUP.md). Текущая Firebase-конфигурация оставлена как необязательный старый вариант и для этого пути не нужна.

## Локальные демо-данные и PIN

Локальный dev-сервер использует `data/schedule.json` и начальный PIN `1234`; это только демо-режим. В реальном бесплатном размещении расписание хранится в закрытой таблице Supabase, а права проверяются Row Level Security. Не публикуйте `.env`, пароли или резервные копии расписания в GitHub.
